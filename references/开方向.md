# /os 开方向 <名> — 新并行方向(自动建 worktree + charter)

目标:一句话给一个新并行方向配齐"隔离工作区 + 作战许可证",用户零手工、任何 agent 零口述接活。

## 步骤(共 6 步)

1. 与用户确认两件事(缺则问,一次问全):方向使命一句话 / 交付物长什么样。**端口自动分配**:按 STATE「并行 dev 端口方案」取下一个空闲端口基数 B(查现有 charters 已占的基数),把完整启动 env 块(backend PORT / 各 MCP env / 前端 --port 与 API target)写进 charter「边界」节,方向会话起 dev 时照抄,保证与主线及其他方向不撞端口。
2. **自动建 worktree(用户不碰 git)**:参数取 STATE「环境事实」的 worktree 约定(路径根 + 分支前缀 + 主线分支);无约定时使用 Git 默认 worktree 位置或用户指定的位置，主线分支读 STATE。执行:
   `git worktree add "<根>/<名>" -b "<分支前缀><名>" <主线分支>`
   建成后 `git -C "<新worktree>" rev-list --count HEAD..<主线分支>` 应为 0(证明基于最新主线)。失败(重名/脏)→ 报给用户,不硬来。
3. 从 `<skill>/assets/charter.template.md` 生成 `<SSOT>/charters/<名>.md`,六节全填:
   使命与背景 / 边界(负责范围 + 端口约定;**在本方向 worktree 干活,commit 后发 commit 信,由主 agent 收割合并进主线**)/ 必读(≤5 个文件,首位恒为 PROJECT-STATE.md)/ 已知资产(可复用代码、研究、skill 的确切路径)/ 产出约定(写哪、格式、DoD)/ 进展日志(空表头)。
4. 在 charter 顶部写「冷启动一句话」(给不认 CLAUDE.md/AGENTS.md 的 agent 用),含 worktree 绝对路径:
   `在 <worktree 绝对路径> 开会话,先读 <SSOT绝对路径>/PROJECT-STATE.md,再读本文件,按边界干活;结束前在进展日志追加一行。`
5. 登记进 PROJECT-STATE.md 的方向表(名 / charter 路径 / worktree 路径 / 状态=待启动)。
6. 告诉用户下一步(**唯一需要用户手动的动作**):"worktree 已建好在 `<路径>`;请在客户端**新开一个会话/窗口、目录选这个 worktree**,第一句 `/os 启动` 即接管本方向。codex/grok 则把 charter 整份贴给它。"

## 铁律

- worktree 自动建,用户不敲 git;开新会话/新窗口是用户在客户端点一下(skill 替不了)。
- charter 单页;边界=负责范围的清晰划分(防交叠撞车),不是权限枷锁;必读绝不超过 5 个文件。
- 方向 worktree 从最新主线切;之后继续迭代前若落后主线,先 merge(见启动.md 代码新鲜度自检)。
