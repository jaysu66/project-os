# /os 清洗 — 记忆大扫除(A 档索引级,原文件不删)

目标:三类产出 —— ①每功能域最新版本进 STATE ②高决策进 DECISIONS ③钥匙/教训进 GOTCHAS;
宿主全局记忆桶(若存在)瘦身为指针,砍常驻 token。

## 步骤(共 6 步)

1. 盘点源:官方桶 MEMORY.md 索引(逐行)+ `<SSOT>` 旧文件(只看文件名与首段)。**A 档不逐篇精读全文。**
2. 每条索引分类四选一:版本状态 / 高决策 / 钥匙教训 / 过时废弃。拿不准 → 快速扫原文首尾再定。
3. 落位:
   - 版本状态 → STATE 的功能域表(功能@版本+入口文件+指针"详见 <原文件>")
   - 高决策 → DECISIONS.md 一条一行:`[日期] 决策一句话(为什么半句)→ 详见 <原文件>`
   - 钥匙教训 → GOTCHAS.md 同格式(可复跑命令直接内联,别只留指针)
   - 过时 → 不动原文件,索引行标 `[过时]`
4. 若宿主存在 agent 的全局记忆桶,项目条目才变一行指针(`→ 仓库 .agent-memory/...`);
   个人偏好/跨项目教训**原样保留**。没有全局记忆桶时跳过此步，不创建平台专属目录。
5. 孤儿桶(同项目其它启动点的桶):有价值条目并入后,桶内 MEMORY.md 只留一行总指针。
6. 汇报:各产出新增条数 / 官方桶行数 前→后 / 标过时几条。**全程零删除,只加指针与标注。**
