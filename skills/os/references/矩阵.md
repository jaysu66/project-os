# 产品矩阵（共享模板）

本文件是可选的项目级注册表模板，不包含任何真实公司、客户或产品数据。

在项目自己的 SSOT 中维护产品条目。每个条目至少说明：名称、目的、负责人、当前状态、源码仓库、依赖和下一次验证时间。不要把真实凭据、客户资料、内部路线图或本机路径写入共享仓库。

```yaml
id: example-product
name: Example Product
purpose: "一句话说明它解决什么问题"
owner: team-or-person
status: draft
repository: https://example.invalid/repository
dependencies: []
next_review: YYYY-MM-DD
```
