# /os 整理 — 让记忆会"忘",才记得住

目标:旧的不删但不再占读取额度;反复出现的坑变成规矩。只在用户说"整理记忆"时做。

## 步骤(共 4 步)

1. 在项目根运行 `node <本 Skill>/scripts/tidy.cjs`(只读),把输出原样给用户。它列出:
   - 超过 30 天、还没归档的会话日志(每份配一行摘要)
   - GOTCHAS 里出现次数 ≥3、还没升级的坑
   - DECISIONS 里有效 / 已推翻各几条
   - STATE 距上次更新的天数
2. 等用户确认。
3. 用户同意归档 → 运行 `node <本 Skill>/scripts/tidy.cjs --apply`:
   每份旧会话追加一行到 `ARCHIVE/YYYY-QN.md`(按会话日期的季度),**原文件保留不删**。
4. 用户同意升级坑 → 手动做(脚本不改语义内容):
   - 把这个坑提炼成一句规矩,追加到 `CONTEXT.md` 的"硬约束":`- <规矩> — 原因:<一句话>(来自 G-xxx)`
   - 在 GOTCHAS 原条目加一行 `**已升级为硬约束**`
   - STATE 超过 7 天没更新 → 按当前事实刷新

最后汇报:归档几份、升级几条、STATE 是否已刷新。

## 不要做

- 不删除任何文件或条目
- 不合并、不改写用户写的原话
