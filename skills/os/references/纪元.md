# /os 纪元 <名> — 重大变故换代(底层重构/换底座/搬家)

目标:旧状态封存、新纪元轻装上阵;**决策与教训跨纪元永续,版本状态按纪元重置**。

## 步骤(共 6 步,main 专属)

1. 身份检查:非 main → 拒绝。与用户确认纪元名和变故一句话描述。
2. 封存:把当前 `PROJECT-STATE.md / DECISIONS.md / GOTCHAS.md / charters/` 整体复制到
   `<SSOT>/epochs/<日期>-<名>/`(只读存档,永不再改)。
3. 写 `epochs/<...>/EPOCH-NOTE.md`(≤20 行):为什么重构 / 什么作废(旧版本状态、旧 charter)/
   什么延续(决策、教训、还活着的方向)。
4. 重写 STATE 为新纪元首版:顶部标 `纪元 N(自 <日期>,前史见 epochs/<...>)`;
   DECISIONS/GOTCHAS **不清空**(延续,只在顶部加纪元分隔行)。
5. 旧 charter 逐份处置:还活的搬回 charters/ 并改边界;死的留在 epochs 标 stale。
6. `/os 广播` 一条纪元切换;若 SSOT 搬家(换 worktree/仓库)→ 更新 git 公共区 `project-os.json` 锚定。
