# /os 体检 — 项目健康检查(只读)

目标:开工前 10 秒确认"会话世界观的地基"没坏。任何会话、任何时候都可跑。

## 步骤(共 2 步)

1. 在项目目录运行 `node <本 Skill>/scripts/os-doctor.cjs`（没有 Node.js 时说明未运行），把输出原样贴给用户。
2. 对每个 ⚠️ 给一行修复建议(下表),等用户点头再动手:

| ⚠️ 项 | 修复动作 |
|---|---|
| 锚定丢失/无效 | 检查 `<git公共区>/project-os.json` 的 ssotDir;丢了就按 STATE 真身位置重写 |
| 分叉 STATE 副本 | 把该副本覆写成墓碑(指向锚定),或删除该 worktree |
| 项目入口协议缺失或版本不一致 | 检查项目自选的 AGENTS.md/CLAUDE.md；没有就报告未配置，不自动覆盖 |
| 锁疑似遗弃(>24h) | 问用户持锁会话是否还活着;死了就删锁文件并广播一句 |
| 只有旧版 INDEX.yaml | 用「/os 接入」,经用户同意后加 `--migrate` 生成 PROJECT-STATE.md;INDEX.yaml 不删 |

## 何时跑

- 用户每天开工前(推荐习惯);
- 归位报告里任何一行自检报 ⚠️ 时;
- 运行过项目自定义开发后端或技能同步工具之后;
- 打包/发版 prepare 前(配合 GOTCHAS 打包铁律)。
