# /os 联动 <产品> <事> — 跨项目协作(显式 pull,复用信箱协议)

## 步骤(共 4 步)

1. Read 产品矩阵注册表(路径见 references/矩阵.md),定位目标产品宿主项目。
2. 宿主**已接入** project-os(有 .agent-memory):
   写 `<对方SSOT>/mailbox/<本项目名>--to--main/REQUEST.md`——背景 2 行 + 请求 1-3 条 + 期望产物/格式 + 回信地址(本项目 SSOT mailbox 路径)。
3. 宿主**未接入**:降级为 task package——把请求整理成自包含 markdown 输出给用户,由用户贴给对方会话;并提示对方项目可 `/os 接入`。
4. 提醒用户:"已写入对方信箱,请到 <产品> 的会话说『/os 信箱』"。

## 铁律

- 联动**只传请求不传写权**:绝不直接改对方项目的代码/STATE。
- 事关本项目主线的回信,由本项目 main 裁决后落地。
- 同一事项一封信,别拆多封刷屏。
