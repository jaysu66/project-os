# /os 广播 — 向所有会话发通知

目标:重大变更让所有并行会话下次开工时自动知晓(它们的「启动」步骤会读最新 3 条)。

## 步骤(共 3 步)

1. 判断值不值得广播(见下方标准):影响全员的事任何负责人都可直接广播;日常改动进展写 commit 信(`mailbox/commits/`)即可,不广播(防噪音)。
2. 在 `<SSOT>/mailbox/BROADCAST.md` **文件末尾**追加一条(新在下;os v2 起改为末尾追加,防多会话整文件重写互踩):
   `- [<日期>] <一句话内容>(详情:<文件路径,可选>)`
   **必须用 shell 真追加**(如 `printf '...' >> BROADCAST.md`),禁止用整文件重写工具"追加"。
3. 只有主 agent 收割时才允许整理该文件(裁旧条目);其他会话只追加。

## 什么值得广播(判断标准)

主线大版本发布 / 主 agent 更替 / 纪元切换 / 目录或端口约定变化 / 影响多方向的决策 / 会撞到别人的接口或数据结构变更。
单方向内部进展**不广播**(写自己 charter + commit 信即可)。
